## Why

現在のキーガイドはフォーム下部に折りたたみ式テーブルとして配置されているが、記載内容が基本キー9件のみで不十分であり（Tab/x/Shift+Tab・記号変換・単語登録など未記載）、またレイアウト上も入力エリアと縦に重なるため入力しながら参照しづらい。SKK初心者が操作を確認しながらタイピングできる体験にするため、サイドパネル化と内容の充実を行う。

## What Changes

- キーガイドを入力エリア右側のサイドパネルに再配置する（広い画面）
- 狭い画面では基本セクションのみをフォーム下部に表示する（現状に近い形）
- キーガイドの内容を6セクションに拡充する：基本 / モード切替 / ▽変換中 / ▼候補選択中 / 記号変換 / 単語登録
- ⚠️ IME注意書きをキーガイドから切り出し、入力欄付近に移動する
- 現在の折りたたみトグルを廃止し、広い画面では常時表示とする

## Capabilities

### New Capabilities

- `key-guide-panel`: 広い画面でのサイドパネル型キーガイド表示。基本セクション＋詳細セクション構成、狭い画面では基本のみのフォールバック表示。

### Modified Capabilities

- `skk-input-ui`: キーガイドのレイアウト・表示要件が変わる（サイドパネル化・セクション構成・常時表示）

## Impact

- `src/components/KeyGuide.tsx`: コンポーネントを全面刷新（内容・レイアウト）
- `src/App.tsx`: フリー入力モードのレイアウト構造を変更（横並び対応）
- `src/App.css`: サイドパネルレイアウト・レスポンシブ対応のCSS追加
- IME注意書きの移動先として `src/components/SkkInputArea.tsx` または `src/App.tsx` を変更
