## MODIFIED Requirements

### Requirement: キーガイドを表示する
システムは主要なSKK操作キーの一覧をキーガイドとして表示しなければならない（SHALL）。広い画面（`min-width: 900px`）ではサイドパネルとして入力エリア右に常時表示する。狭い画面では基本セクションのみをフォーム下部に表示する。折りたたみトグルは不要。

#### Scenario: 広い画面でのサイドパネル表示
- **WHEN** 画面幅が900px以上の状態でページを開く
- **THEN** キーガイドが入力エリアの右側にサイドパネルとして常時表示される

#### Scenario: 狭い画面での下部表示
- **WHEN** 画面幅が900px未満の状態でページを開く
- **THEN** 基本キー（大文字→変換開始、Space→候補選択、Enter→確定、Ctrl+G→キャンセル、Ctrl+J→ひらがな）の説明がフォーム下部に表示される

## ADDED Requirements

### Requirement: IME注意書きを入力欄の付近に表示する
システムはシステムIMEをオフにするよう促す注意書きを、SKK入力欄の直上または直近に表示しなければならない（SHALL）。この注意書きはキーガイドの内部には含めない。

#### Scenario: IME注意書きの表示位置
- **WHEN** フリー入力モードでページを表示する
- **THEN** ⚠️ IMEオフの注意書きが入力欄付近（キーガイドの外）に表示される
