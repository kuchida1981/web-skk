## MODIFIED Requirements

### Requirement: 問題表示
ゲーム画面には現在の問題文・進捗 (例: 3/10)・タイマーを表示しなければならない（SHALL）。SKK入力欄にフォーカスが当たった状態で始まらなければならない（SHALL）。タイマーは小数点以下第1位（0.1秒単位）で表示しなければならない（SHALL）。

#### Scenario: 問題画面の表示内容
- **WHEN** 問題が表示される
- **THEN** 問題文・進捗カウンター・経過タイム（例: `1.2 秒`）・途中終了ボタンが画面上に存在する

### Requirement: 正誤判定
アプリは committed と問題文テキストを Unicode コードポイント単位で完全比較しなければならない（SHALL）。

#### Scenario: 正解
- **WHEN** committed が問題文と完全一致した状態で提出される
- **THEN** 正解として扱い、committed をリセットして次の問題へ進む (最終問の場合は結果画面へ)

#### Scenario: 不一致
- **WHEN** committed が問題文と一致しない状態で提出される
- **THEN** 不一致の文字位置を赤くハイライトした問題文を表示し、committed はリセットせず同じ問題の再入力を求める（ユーザーは入力内容を修正して再送信できる）
