# key-guide-panel Specification

## Purpose
キーガイドのサイドパネル表示・セクション構成・レスポンシブ対応に関する要件。

## Requirements

### Requirement: 広い画面でサイドパネルとして常時表示する
広い画面（`min-width: 900px` 程度）では、システムはキーガイドを入力エリアの右側にサイドパネルとして常時表示しなければならない（SHALL）。パネルに折りたたみトグルは不要。

#### Scenario: サイドパネルの常時表示
- **WHEN** 画面幅が900px以上の状態でページを開く
- **THEN** キーガイドが入力エリアの右側に表示されている

---

### Requirement: 5セクション構成でキーバインドを網羅する
キーガイドは以下の5セクションを含まなければならない（SHALL）：基本 / モード切替 / ▽変換中 / ▼候補選択中 / 単語登録。

#### Scenario: 基本セクションの表示
- **WHEN** キーガイドを表示する
- **THEN** 大文字・Space・Enter/Ctrl+J・Ctrl+G の説明が「基本」セクションに表示される

#### Scenario: モード切替セクションの表示
- **WHEN** キーガイドを表示する
- **THEN** Q・l・L のモード切替説明が「モード切替」セクションに表示される

#### Scenario: ▽変換中セクションの表示
- **WHEN** キーガイドを表示する
- **THEN** Space/Tab・大文字（送り仮名）・q（カタカナ確定）・Enter/Ctrl+J・Ctrl+G・Backspace の説明が「▽変換中」セクションに表示される

#### Scenario: ▼候補選択中セクションの表示
- **WHEN** キーガイドを表示する
- **THEN** Space/Tab（次候補）・x/Shift+Tab（前候補）・Enter/Ctrl+J・Backspace の説明が「▼候補選択中」セクションに表示される

#### Scenario: 単語登録セクションの表示
- **WHEN** キーガイドを表示する
- **THEN** 候補切れ時の自動登録モード移行・Enter/Ctrl+J（登録確定）・Ctrl+G（登録キャンセル）の説明が「単語登録」セクションに表示される

---

### Requirement: 狭い画面では基本セクションのみを下部に表示する
画面幅が狭い場合（`max-width: 899px`）、システムは基本セクションのみをフォーム下部に表示し、詳細セクションは非表示にしなければならない（SHALL）。

#### Scenario: 狭い画面での表示
- **WHEN** 画面幅が900px未満の状態でページを開く
- **THEN** 基本セクションのみが表示され、モード切替・▽変換中・▼候補選択中・単語登録の各セクションは表示されない
